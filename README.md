## 💡 แนวคิดพื้นฐานสำคัญ (Fundamental Concept)

* **ความหมายของคำว่า "อิสลาม" (Islam):** มาจากรากศัพท์ภาษาอาหรับ **س-ل-ม (S-L-M)** ซึ่งมีความหมายคู่ขนานคือ **"สันติสุข" (Salam)** และ **"การยอมจำนนนอบน้อมต่อพระประสงค์ของพระเจ้า" (Istislam)**
* **มุสลิม (Muslim):** หมายถึง บุคคลผู้ยอมรับและนอบน้อมปฏิบัติตามเจตนารมณ์ของพระผู้เป็นเจ้า
* **อัลลอฮ์ (Allah):** เป็นคำนามเฉพาะภาษาอาหรับที่หมายถึง **"พระเจ้าเที่ยงแท้องค์เดียว"** (The One True God) ซึ่งชาวอาหรับคริสเตียนและอาหรับยิวก็ใช้คำนี้เรียกพระเจ้าเช่นกัน
